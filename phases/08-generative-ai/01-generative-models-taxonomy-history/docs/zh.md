# 生成模型 —— 分类与历史

> 每个图像模型、文本模型、视频模型和 3D 模型都可以归入五个类别之一。选错类别，你会与数学搏斗数周；选对类别，该领域过去十二年的进展就能清晰地印在你脑中。

**类型：** 学习
**语言：** Python
**前置知识：** 阶段 2（机器学习基础）、阶段 3（深度学习核心）、阶段 7 · 14（Transformers）
**时间：** ~45 分钟

## 问题

生成模型只做一件事：给定从某个未知分布 `p_data(x)` 中抽取的训练样本，输出看起来同样来自该分布的新样本。人脸、句子、MIDI 文件、蛋白质结构——如果你眯起眼睛看，都是同一个问题。

难点在于 `p_data` 存在于一个数百万维的空间中（一张 512×512 的 RGB 图像约有 786k 维），样本分布在这个空间中的一个薄流形上，而你只有大约 1000 万个样本。暴力计算密度毫无希望。每个生成模型都是一种折中，用一个难题换取一个稍微不那么难的难题。

过去十二年有五个家族存活了下来。了解每个家族做出了怎样的折中，就能明白为什么它在某些任务上表现出色，而在另一些任务上却崩溃。

## 概念

![五类生成模型——按建模对象分类](../assets/taxonomy.svg)

**1. 显式密度，可计算。** 将 `log p(x)` 写成可以实际求和的形式。自回归模型（PixelCNN、WaveNet、GPT）对 `p(x) = ∏ p(x_i | x_<i)` 进行因式分解。标准化流（RealNVP、Glow）将 `p(x)` 构建为简单基分布的可逆变换。优点：精确似然、清晰的训练损失。缺点：自回归推理是顺序的（长序列慢），流需要可逆架构（架构受限）。

**2. 显式密度，近似。** 从下方约束 `log p(x)`（ELBO）并优化该约束。VAE（Kingma 2013）使用带有变分后验的编码器-解码器结构。扩散模型（DDPM，Ho 2020）训练一个去噪器，隐式地优化一个加权 ELBO。扩散是 2026 年图像、视频和 3D 领域的主导骨干网络。

**3. 隐式密度。** 完全跳过密度；学习一个生成器 `G(z)` 来生成样本，以及一个判别器 `D(x)` 来区分真假。GAN（Goodfellow 2014）。推理速度快（一次前向传播），但训练时 notoriously 不稳定。StyleGAN 1/2/3 即使在 2026 年仍然是固定领域照片级真实感（人脸、卧室）的最先进水平。

**4. 基于分数 / 连续时间。** 直接学习对数密度 `∇_x log p(x)` 的梯度（即分数）。Song & Ermon（2019）证明了分数匹配将扩散推广到了 SDE。流匹配（Lipman 2023）是 2024-2026 年的热门技术：无需模拟的训练、更直的路径、比 DDPM 快 4-10 倍的采样。Stable Diffusion 3、Flux、AudioCraft 2 都使用流匹配。

**5. 基于离散码的自回归。** 用 VQ-VAE 或残差量化器将高维数据压缩成短序列的离散 token，然后用 Transformer 建模该 token 序列。Parti、MuseNet、AudioLM、VALL-E、Sora 的 patch tokenizer 都采用这种方法。这是第 1 类加上一个学习得到的 tokenizer。

## 五问分诊法

当一篇新的生成模型论文发布时，在阅读方法部分之前，先回答这五个问题。

1. **建模对象是什么？** 像素、潜在变量、离散 token、3D 高斯、网格、波形？
2. **密度是显式还是隐式？** 他们是否写出了 `log p(x)`？
3. **采样：单步还是迭代？** 迭代意味着更慢的推理；单步通常意味着对抗或蒸馏。
4. **条件化：无条件、类别、文本、图像、姿态？** 这决定了损失函数和架构脚手架。
5. **评估指标：FID、CLIP 分数、IS、人类偏好、任务准确率？** 每个都有已知的失效模式（见第 14 课）。

在本阶段的每一课中，你都会重新回答这五个问题。到最后，它们将成为你的本能。

## 动手实现

本课的代码是一个轻量级可视化：用三种简单方法（核密度估计、离散直方图和最近邻"类 GAN"生成器）从样本中拟合一维高斯混合，让你能在单屏可打印的问题上看显式密度与隐式密度的区别。

运行 `code/main.py`。它从双峰高斯混合中抽取 2000 个样本，然后输出：

```
explicit density (histogram): p(x in [-0.5, 0.5]) ≈ 0.38
approximate density (KDE):     p(x in [-0.5, 0.5]) ≈ 0.41
implicit (nearest-sample gen): 20 new samples printed, no p(x)
```

注意：前两种方法允许你问"这个点有多大概率？"第三种则不能。这就是*显式与隐式*的区别，它将在未来的每一课中至关重要。

## 应用

2026 年，哪个家族适合哪个任务？

| 任务 | 最佳家族 | 原因 |
|------|---------|------|
| 照片级真实人脸，窄领域 | StyleGAN 2/3 | 仍然最清晰，推理最快。 |
| 通用文本到图像 | 潜在扩散 + 流匹配 | SD3、Flux.1、DALL-E 3。 |
| 快速文本到图像 | 整流流 + 蒸馏 | SDXL-Turbo、SD3-Turbo、LCM。 |
| 文本到视频 | 扩散 Transformer + 流匹配 | Sora、Veo 2、Kling。 |
| 语音 + 音乐 | 基于 token 的 AR（AudioLM、VALL-E、MusicGen）或流匹配（AudioCraft 2） | 离散 token 扩展成本低。 |
| 3D 场景 | 高斯溅射拟合，扩散先验 | 3D-GS 用于重建，扩散用于新视角。 |
| 密度估计（不采样） | 流 | 唯一具有精确 `log p(x)` 的家族。 |
| 模拟 / 物理 | 流匹配，分数 SDE | 直线路径，平滑向量场。 |

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|-----------|---------|
| 生成模型 | "它能生成新东西" | 学习 `p_data(x)` 的采样器，可选择性暴露 `log p(x)`。 |
| 显式密度 | "你可以计算它" | 模型提供闭式或可计算的 `log p(x)`。 |
| 隐式密度 | "GAN 风格" | 只有采样器——无法计算给定点的 `p(x)`。 |
| ELBO | "证据下界" | `log p(x)` 的可计算下界；VAE 和扩散模型优化它。 |
| 分数 | "对数密度的梯度" | `∇_x log p(x)`；扩散和 SDE 模型学习这个场。 |
| 流形假设 | "数据生活在曲面上" | 高维数据集中在低维流形上；这是降维有效的原因。 |
| 自回归 | "预测下一个片段" | 将联合分布分解为条件分布的乘积。 |
| 潜在变量 | "压缩编码" | 低维表示，解码器可从中重建输入。 |

## 生产备注：五个家族，五种推理形态

每个家族对应不同的推理服务器成本曲线。生产推理文献将 LLM 推理框架为预填充 + 解码；同样的分解在这里也适用：

- **自回归（第 1 和第 5 类）。** 顺序解码主导延迟；KV 缓存、连续批处理和推测解码都直接适用。
- **VAE / 扩散 / 流匹配（第 2 和第 4 类）。** 没有 LLM 意义上的解码。成本 = `num_steps × step_cost`，而 `step_cost` 是在完整潜在分辨率上的 Transformer 或 U-Net 前向传播。生产调优旋钮是步数（DDIM / DPM-Solver / 蒸馏）、批大小和精度（bf16 / fp8 / int4）。
- **GAN（第 3 类）。** 一次前向传播。没有调度，没有 KV 缓存。TTFT ≈ 总延迟。这就是 StyleGAN 在窄领域 UX 上仍然获胜的原因。

当你在论文摘要中看到"比扩散更快"时，将其翻译为"更少步数 × 相同步成本"或"相同步数 × 更便宜步成本"。其他都是营销。
