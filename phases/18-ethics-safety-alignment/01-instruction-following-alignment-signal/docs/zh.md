# 指令跟随作为对齐信号

> 后续所有对 RLHF 的批评都针对这一流水线。在你研究优化压力如何扭曲代理目标之前，你必须先看清这个代理目标本身。InstructGPT（Ouyang 等，2022）定义了参考架构：在指令-回复对上进行的监督微调、基于成对偏好排序训练的奖励模型，以及针对该奖励模型并使用 KL 散度惩罚约束 SFT 策略的 PPO。一个 1.3B 参数的 InstructGPT 比 175B 参数的 GPT-3 更受青睐。正是这一单一结果，使得 2026 年每家前沿实验室仍在交付带有 RLHF 特征的后训练流水线。

**类型：** 学习
**语言：** Python（标准库，玩具版三阶段流水线）
**前置知识：** 第 10 阶段 · 06（SFT）、第 10 阶段 · 07（RLHF）、第 10 阶段 · 08（DPO）
**耗时：** 约 45 分钟

## 学习目标

- 说出 InstructGPT 流水线的三个阶段及其各自使用的损失函数。
- 解释为何 1.3B 的指令微调模型在人类偏好评估中击败了原始的 175B GPT-3。
- 说明第三阶段中的 KL 惩罚旨在防止什么，以及移除它为何会导致模式寻求行为（mode-seeking behaviour）。
- 描述对齐税（alignment tax）以及 Ouyang 等人用于缓解它的 PPO-ptx 方法。

## 问题背景

预训练语言模型擅长续写文本，而非回答问题。向 GPT-3 提问“写一个反转列表的 Python 函数”，你经常得到的却是另一个提示词，因为大部分训练分布是网页文本，模型会自然地继续生成更多网页文本。模型正在完成它的工作——只是这份工作错了。

各严肃实验室用来解决此问题的代理目标是人类偏好。将两个续写结果交给标注员；标注员选出更好的一个；奖励模型据此学习标注员的偏好。随后，强化学习循环将策略推向奖励模型评分较高的输出。这就是用三句话概括的完整 InstructGPT 核心论点。论文的其余部分全是工程实现。

## 核心概念

### 第一阶段：监督微调（SFT）

收集提示-回复对，其中回复是善意的人类作者会写出的内容。Ouyang 等人使用了来自标注员和 OpenAI API 的 1.3 万个提示。使用标准的交叉熵损失在该数据上对基础模型进行微调。

SFT 赋予你的能力：模型现在会回答问题，而不是单纯地续写。SFT 未赋予你的能力：当存在多个合理答案时，关于标注员更偏好哪一个的任何信号。

### 第二阶段：奖励模型（RM）

对于每个提示，从 SFT 模型中采样 K 个续写结果。标注员对其进行排序。训练一个奖励模型，使其能为任意提示-回复对打分，从而满足：对于 `y_w` 优于 `y_l` 的对子：

```
L_RM = -log sigmoid(r(x, y_w) - r(x, y_l))
```

这是 Bradley-Terry 成对偏好损失。奖励模型通常以 SFT 模型为初始化基础，并将语言模型头替换为标量头。

奖励模型体积很小：对于 175B 的 InstructGPT，6B 参数就足够了。它们也很脆弱——论文的第 5 节主要讨论了在小规模实验中出现的奖励黑客（reward-hacking）行为。

### 第三阶段：带 KL 惩罚的 PPO

定义目标函数：

```
J(pi) = E_{x~D, y~pi(.|x)} [ r(x, y) ] - beta * KL(pi(.|x) || pi_SFT(.|x))
```

使用 PPO 最大化该目标。KL 项用于防止 `pi` 偏离 SFT 策略过远。如果没有它，优化器会找到对抗样本——即在奖励模型下得分很高的字符串，这是因为奖励模型从未见过它们，而非因为人类真正偏好它们。

KL 系数 `beta` 是 RLHF 中最重要的超参数。设置过低：导致奖励黑客攻击。设置过高：无法带来相对于 SFT 的提升。

### 对齐税

经过 RLHF 后，模型虽然更受人类青睐，但在标准基准测试（SQuAD、HellaSwag、DROP）上的表现却出现退化。Ouyang 等人将其称为对齐税（alignment tax），并使用 PPO-ptx 加以修复：将预训练梯度混合到强化学习目标中，以防止模型遗忘那些从未被奖励过的下游任务的处理能力。

```
J_ptx(pi) = J(pi) + gamma * E_{x~D_pretrain} [ log pi(x) ]
```

PPO-ptx 已成为标准做法。Anthropic、DeepMind 和 Meta 均采用了其某种变体。

### 实验结果

在标注员的评估中，1.3B 的 InstructGPT（SFT + RM + PPO-ptx）约有 70% 的概率优于 175B 的基础版 GPT-3。在生产流量中的隐藏测试提示下，这一优势差距进一步扩大。从这个数字中可以得出两点结论：

1. 对齐与能力是不同的维度。175B 模型拥有更强的能力；1.3B 模型拥有更高的对齐度；标注员更偏好对齐后的版本。
2. 能力的下限由基础模型决定。你无法通过 RLHF 让一个基础模型掌握它从未见过的知识事实。

### 为何它是第 18 阶段的参考基准

后续课程中的每一项批评——奖励黑客（第 2 课）、DPO（第 3 课）、迎合倾向（sycophancy，第 4 课）、CAI（第 5 课）、休眠智能体（第 7 课）、对齐伪装（第 9 课）——都在质疑该流水线的某个环节。奖励黑客攻击的是第二阶段。DPO 将第二和第三阶段合并。CAI 取代了人类标注员。迎合倾向现象表明标注员是一种有偏见的信号。对齐伪装现象表明策略可以完全绕过第三阶段。如果你脑海中没有先建立起这套流水线的全貌，就无法理解其中的任何一项批评。

## 动手实践

`code/main.py` 在玩具偏好数据上模拟了这三个阶段。基础的“策略”是一个作用于动作 {A, B, C} 的有偏硬币。第一阶段 SFT 模仿标注员在 200 个提示上的动作。第二阶段基于 500 组成对排序拟合 Bradley-Terry 奖励模型。第三阶段执行简化的 PPO 更新，并加入针对 SFT 策略的 KL 惩罚。你可以观察奖励上升、KL 散度增长以及策略漂移的过程——并且可以关闭 KL 项，看看奖励黑客行为如何在 50 次更新步骤内显现。

需要关注的指标：

- 开启 `beta = 0.1` 与 `beta = 0.0` 时的奖励轨迹对比。
- 训练过程中 KL(pi || pi_SFT) 的变化。
- 最终动作分布与标注员偏好的对比。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| SFT | “指令微调” | 第一阶段：在提示-回复对上使用交叉熵进行微调 |
| 奖励模型 (Reward model) | “RM” | 基于 (提示, 回复) 的标量回归器，使用 Bradley-Terry 损失在成对标签上训练 |
| Bradley-Terry | “成对偏好损失” | -log sigmoid(r_w - r_l)；将成对排序转化为二分类问题 |
| KL 惩罚 | “正则化项” | `beta * KL(pi \|\| pi_SFT)` —— 使强化学习策略保持在 SFT 锚点附近 |
| PPO-ptx | “带预训练混合的 PPO” | 将一部分预训练对数似然添加到 PPO 目标中，以抵消对齐税的影响 |
| 对齐税 (Alignment tax) | “RLHF 性能回退” | RLHF 后在标准基准测试上出现的性能下降，且这些基准并非 RLHF 的目标 |
| 标注员偏好 (Labeler preference) | “地面真值” | 人类排序的样本；奖励模型仅是对此的统计代理，而非对“人类价值观”的代理 |
