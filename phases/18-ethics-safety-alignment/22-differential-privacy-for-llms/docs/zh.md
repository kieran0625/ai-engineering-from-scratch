# 大语言模型的差分隐私

> DP-SGD 仍是标准方法——注入噪声的梯度更新可提供形式化的 (ε, δ) 保证。其在计算、内存和模型效用上的开销显著；参数高效的 DP 微调（LoRA + DP-SGD）是 2025 年的常见配置（ACM 2025）。存在两组相互矛盾的证据：基于金丝雀的会员推断（Duan 等，2024）报告对大语言模型的成功率有限；训练数据提取（Carlini 等，2021；Nasr 等，2025）则恢复了大量逐字记忆。解决方案（arXiv:2503.06808，2025年3月）：差异在于测量对象——插入的金丝雀数据与“最易提取”的数据。新的金丝雀设计实现了无需影子模型的基于损失的 MIA，并首次对使用真实数据训练且具备合理 DP 保证的 LLM 进行了非平凡的 DP 审计。替代方案：PMixED（arXiv:2403.15638）——通过专家混合机制在推理时对下一个 token 分布进行私有预测；DP 合成数据生成（Google Research 2024）。新兴攻击：基于 LLM 反馈的差分隐私逆转——置信度分数泄露。

## 问题背景

LLM 会记忆。Carlini 等（2021）的研究表明，生产级语言模型可按需逐字复现训练文本。DP 是一种形式化防御手段：通过训练使模型输出对任意单个训练样本不可证明地不敏感（即满足隐私保证）。2024-2025 年的证据表明，DP-SGD 是必要的，但实际部署的 ε 值可能与威胁模型不匹配。

## 核心概念

### (ε, δ)-差分隐私

若对于任意仅相差一个样本的两个数据集 D 和 D'，以及任意事件 S，随机算法 M 满足：
P(M(D) ∈ S) ≤ e^ε * P(M(D') ∈ S) + δ。

直观理解：输出分布足够接近（由 ε 参数化），使得除概率 δ 外，无法可靠地推断出任何单个个体的贡献。

### DP-SGD

Abadi 等（2016）。标准流程如下：
1. 采样一个小批量（mini-batch）。
2. 计算每个样本的梯度。
3. 将每个样本的梯度裁剪至阈值 C。
4. 对裁剪后的梯度求和，并添加标准差为 σ * C 的高斯噪声。
5. 使用加噪后的梯度总和更新模型参数。

隐私成本由预算追踪器（Accountant，如 Moments Accountant 或 Rényi DP accountant）进行记录。LLM 文献中报告的 ε 值因威胁模型、数据敏感性和效用目标的不同而差异巨大；不存在通用的“安全”默认 ε 值。在某些 LLM 训练设置中，已发表的示例大致在 ε ≈ 1–10 范围内，但这仅为示意——并非推荐的默认值。较低的 ε 通常意味着需要注入更多噪声，可能导致更大的效用损失。

### LoRA + DP-SGD

对前沿模型进行完整的 DP-SGD 训练开销过大。LoRA（Hu 等，2022）将梯度更新限制在一个小型适配器上，从而降低了每个样本梯度的存储需求。LoRA + DP-SGD 是 2025 年的常见配置。DP 保证仅适用于该适配器；基础模型保持固定不变。

### 2024-2025 年的争议

两条证据线：

- **金丝雀 MIA（Duan 等，2024）**。在训练数据中插入独特的金丝雀样本，测量成员推断攻击者能否识别它们。报告指出对语言模型的成功率有限。这表明 MIA 很难实施。
- **训练数据提取（Carlini 2021，Nasr 等，2025）**。向模型提供前缀提示，测量其是否能恢复训练集中的逐字文本。报告指出存在大量记忆现象。这表明在相关意义上，MIA 很容易实施。

2025年3月的解决方案（arXiv:2503.06808）：两者测量的是不同事物。MIA 针对插入的金丝雀询问“样本 e 是否在 D 中？”。提取攻击询问“我能从 D 中恢复什么？”。真正影响隐私的是“最易提取”的样本；金丝雀由于未针对可提取性进行优化，因此低估了这一点。

新的金丝雀设计。无需影子模型的基于损失的 MIA。首次对使用真实数据训练且具备合理 DP 保证的 LLM 进行了非平凡的 DP 审计。

### DP 训练的替代方案

- **PMixED（arXiv:2403.15638）**。推理时的私有预测。基于下一个 token 分布的专家混合机制；每个专家仅接触部分训练数据分片；聚合过程添加噪声以满足 DP。完全避免了 DP 训练。
- **DP 合成数据生成（Google Research 2024）**。使用 DP-SGD 进行 LoRA 微调，采样合成数据，并在合成数据上训练下游分类器。

两者以采用不同威胁模型为代价，规避了完整 DP 训练的效用损失。

### 基于 LLM 反馈的差分隐私逆转

2025 年新兴的攻击方式。利用经过 DP 训练的模型的置信度分数作为预言机（oracle）来重新识别个体。即使模型输出本身没有泄露，置信度分布也可能泄露信息。

防御措施：不暴露置信度，或在暴露前对其进行截断/量化。这是在 (ε, δ)-DP 训练之外的一项额外要求。

## 动手实践

`code/main.py` 在玩具二分类数据集上模拟 DP-SGD。你可以遍历噪声乘子 σ 和裁剪范数 C，并跟踪 (ε, δ) 预算与准确率损耗。一次“金丝雀攻击”会插入一个独特的训练样本，并测量在对数损失测试中，DP 处理前后能否检测到它。

## 交付成果

本课将产出 `outputs/skill-dp-audit.md`。针对某语言模型部署中的 DP 声明，它将执行审计：检查 (ε, δ) 值、使用的预算追踪器、MIA 评估协议，以及是否已评估过置信度暴露向量。

## 练习

1. 运行 `code/main.py`。在 {0.5, 1.0, 2.0} 范围内遍历 σ，报告 (ε, δ) 与准确率的权衡关系。找出效用崩溃的临界点。

2. 实现金丝雀插入与对数损失测试。测量在 σ = 1.0 时，DP-SGD 处理前后的检测率。

3. 阅读 Nasr 等（2025）关于训练数据提取的论文。为什么在中等 ε 值下提取成功率不会崩溃？这对将 MIA 作为评估指标有何启示？

4. 设计一个完全在推理时运行的 PMixED（arXiv:2403.15638）部署方案。PMixED 解决了哪些 DP-SGD 未覆盖的威胁模型？

5. 简述基于 LLM 反馈的 DP 逆转攻击。设计一种限制置信度分数泄露的对策，并估算其部署成本。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| DP | “(ε, δ)-差分隐私” | 形式化隐私：相邻数据集变化下输出分布保持相近 |
| DP-SGD | “注入噪声的 SGD” | 梯度裁剪 + 高斯噪声添加；标准 DP 训练方法 |
| LoRA + DP-SGD | “高效私有微调” | 在低秩适配器上应用 DP-SGD；2025 年标准配置 |
| MIA | “成员推断” | 判断某个样本是否曾出现在训练数据中的攻击 |
| Canary | “插入的水印样本” | 用于衡量 DP 泄露程度的独特训练样本 |
| PMixED | “私有推理混合” | 基于下一个 token 分布的专家混合机制实现推理时 DP |
| DP Reversal | “置信度泄露攻击” | 利用模型置信度作为预言机进行重新识别的攻击 |
