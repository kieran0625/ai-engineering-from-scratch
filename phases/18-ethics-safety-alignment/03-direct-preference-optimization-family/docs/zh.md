# 直接偏好优化系列算法

> Rafailov 等人（2023）表明，RLHF 的最优解在偏好数据上具有闭式解，因此你可以跳过显式的奖励模型，直接优化策略。这一洞见催生了一个算法家族——IPO、KTO、SimPO、ORPO、BPO——它们各自修复了 DPO 的某种失效模式。到了 2026 年，直接对齐算法发布的先进后训练运行次数已超过 PPO。但第 2 课中的“过度优化曲线”依然适用：直接对齐算法并未逃脱古德哈特定律（Goodhart's Law），只是将引发问题的位置从别处转移了过来。

**类型：** 学习
**语言：** Python（标准库，六变体偏好损失比较器）
**前置知识：** 阶段 18 · 01（InstructGPT）、阶段 18 · 02（奖励黑客攻击）、阶段 10 · 08（DPO 基础）
**耗时：** 约 75 分钟

## 学习目标

- 从带 KL 约束的 RLHF 最优解推导出 DPO 的闭式解。
- 说明 IPO、KTO、SimPO、ORPO、BPO 各自修复了 DPO 的哪种失效模式。
- 区分“隐式奖励差距”与“偏好强度”，并解释 IPO 的恒等映射为何重要。
- 解释为何 Rafailov 等人（NeurIPS 2024）证明，尽管没有显式奖励模型，直接对齐算法（DAAs）仍会过度优化。

## 问题背景

RLHF 目标函数（第 1 课）：

```
max_pi E_{x,y~pi} [ r(x, y) ] - beta * KL(pi || pi_ref)
```

其已知最优解为：

```
pi*(y|x) = (1/Z(x)) * pi_ref(y|x) * exp(r(x, y) / beta)
```

因此，奖励被隐式定义为最优策略与参考策略之比的对数：

```
r(x, y) = beta * log(pi*(y|x) / pi_ref(y|x)) + beta * log Z(x)
```

将其代入 Bradley-Terry 偏好似然函数中，由于配分函数 `Z(x)` 仅依赖于 `x`，它会相互抵消。最终剩下的仅是关于策略参数的损失函数——无需奖励模型。这就是 DPO。

棘手之处在于：该推导假设最优解可达、偏好数据符合分布内、且参考策略是真实的模态锚点。这些条件在实际中均无法完全满足。该家族的每个成员都针对不同的假设违背情况进行了修复。

## 核心概念

### DPO (Rafailov 等人, 2023)

```
L_DPO = -log sigmoid(
  beta * log(pi(y_w | x) / pi_ref(y_w | x))
  - beta * log(pi(y_l | x) / pi_ref(y_l | x))
)
```

可能出现的问题：

- 隐式奖励差距 `beta * (log(pi/pi_ref)_w - log(pi/pi_ref)_l)` 是无界的。极小的偏好差异可能导致任意大的差距。
- 损失函数驱使选中项和拒绝项的对数概率向相反方向变化。只要拒绝项下降得更快，它就可以将选中项的绝对对数概率拉低。这就是“退化选中响应”现象。
- 分布外偏好（罕见样本对 vs 罕见样本对）会产生任意的隐式奖励。

### IPO (Azar 等人, 2024)

恒等偏好优化（Identity Preference Optimization）用偏好概率上的恒等映射替换了对数 sigmoid 函数。损失函数变为针对有界目标的平方误差：

```
L_IPO = (log(pi(y_w | x) / pi_ref(y_w | x)) - log(pi(y_l | x) / pi_ref(y_l | x)) - 1/(2 beta))^2
```

间隔由 `1/(2 beta)` 限制。偏好强度与隐式奖励差距成正比。不会出现爆炸性增长。

### KTO (Ethayarajh 等人, 2024)

卡尼曼-特沃斯基优化（Kahneman-Tversky Optimization）完全摒弃了成对结构。给定单个带标签的输出以及二元“可取”或“不可取”信号，它将其映射为前景理论效用：

```
v(x, y) = sigma(beta * log(pi(y|x) / pi_ref(y|x)) - z_ref)
```

其中收益和损失赋予不同的权重（损失厌恶）。优势在于：可以使用未配对的数据，这类数据要丰富得多。

### SimPO (Meng 等人, 2024)

简单偏好优化（Simple Preference Optimization）使训练信号与生成过程对齐。完全移除参考策略，并按长度归一化对数似然：

```
L_SimPO = -log sigmoid(
  (beta / |y_w|) * log pi(y_w | x)
  - (beta / |y_l|) * log pi(y_l | x)
  - gamma
)
```

并引入间隔 `gamma` 以稳定训练。长度归一化消除了利用 DPO 长度偏差失效模式的动机（构造上，更长的 `y_w` 会产生更大的对数概率差距）。

### ORPO (Hong 等人, 2024)

赔率偏好优化（Odds-Ratio Preference Optimization）在标准的 SFT 负对数似然基础上添加了一个偏好项：

```
L_ORPO = L_NLL(y_w) + lambda * L_OR
L_OR = -log sigmoid(log(odds(y_w) / odds(y_l)))
```

无需参考策略——SFT 项充当正则化器。从基座模型到对齐模型只需单阶段训练。无需单独的 SFT 检查点。

### BPO (ICLR 2026 投稿, OpenReview id=b97EwMUWu7)

指出了“退化选中响应”问题：DPO 保留了排序 `y_w > y_l`，但 `y_w` 的绝对对数概率可能会下降。BPO 增加了一行修正代码，对选中响应概率的下降进行惩罚。在数学推理任务上，相较于 DPO，其在 Llama-3.1-8B-Instruct 上的准确率提升了 10.1%。

### 普遍结论：直接对齐算法仍会过度优化

Rafailov 等人的《直接对齐算法中奖励模型过度优化的缩放定律》（NeurIPS 2024）在不同 KL 预算下使用 DPO、IPO、SLiC 在多个数据集上训练策略。真实奖励与 KL 散度的曲线呈现出与 Gao 等人相同的先升后降形态。训练过程中隐式奖励会查询分布外样本；KL 正则化无法稳定这一现象。

直接对齐算法并未逃脱古德哈特定律。它们只是将引发问题的表面从“奖励模型过度优化”转变为“参考策略比率过度优化”。通用的解决方案——更好的数据、集成方法、早停机制——同样适用于两者。

### 如何选择（2026 年视角）

- 如果你拥有大量成对偏好数据：使用保守 beta 值的 DPO；若存在明显的长度偏差，则使用 SimPO。
- 如果你有未配对的二元反馈：使用 KTO。
- 如果你希望从基座模型开始单阶段流水线：使用 ORPO。
- 如果你在 DPO 日志中看到选中的对数概率下降：使用 BPO。
- 如果偏好强度差异很大且 DPO 趋于饱和：使用 IPO。

每个实验室都会在基准测试集上运行这五种算法，并为每个任务挑选优胜者。数学推理和安全对齐的最优解没有理由相同。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|-----------------|------------------------|
| DPO | “无奖励模型的 RLHF” | 源自 RLHF 闭式最优解的损失函数；仅涉及策略参数 |
| 隐式奖励 | “对数比率” | `beta * log(pi(y\|x) / pi_ref(y\|x))` —— DPO 隐含的奖励 |
| IPO | “有界 DPO” | 用恒等映射替换对数 sigmoid；隐式奖励差距受 `1/(2 beta)` 限制 |
| KTO | “非配对 DPO” | 基于前景理论效用，处理单标签并引入损失厌恶 |
| SimPO | “无参考 DPO” | 长度归一化的对数似然加间隔；无需参考策略 |
| ORPO | “单阶段 DPO” | 负对数似然加赔率偏好项；从基座模型单次遍历训练 |
| BPO | “保选中 DPO” | DPO 加上对选中响应绝对对数概率下降的惩罚项 |
| 退化选中 | “选中项概率下降” | 只要拒绝项下降得更快，DPO 就会降低选中项的对数概率 |
| DAA | “直接对齐算法” | 任何跳过显式奖励模型的偏好损失方法 |
