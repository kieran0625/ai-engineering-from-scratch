# 红队测试：PAIR 与自动化攻击

> Chao, Robey, Dobriban, Hassani, Pappas, Wong（NeurIPS 2023，arXiv:2310.08419）。PAIR（Prompt Automatic Iterative Refinement，提示词自动迭代优化）是标准的自动化黑盒越狱方法。一个带有红队系统提示词的攻击者 LLM 会为目标 LLM 迭代地提出越狱提示词，并将尝试和响应累积在其自身的对话历史中作为上下文反馈。PAIR 通常在 20 次查询内即可成功，比 GCG（Zou 等人的词元级梯度搜索）效率高出一个数量级以上，且无需白盒访问权限。如今，PAIR 已与 GCG、AutoDAN、TAP 和 Persuasive Adversarial Prompt 一起，成为 JailbreakBench（arXiv:2404.01318）和 HarmBench 中的标准基线。

**类型：** 构建

## 学习目标

- 描述 PAIR 算法：攻击者系统提示词、迭代优化、上下文反馈。
- 解释为何在目标为黑盒时，PAIR 的效率严格优于 GCG。
- 列举另外四种自动化攻击基线（GCG、AutoDAN、TAP、PAP），并说明每种的一个显著特征。
- 描述 JailbreakBench 和 HarmBench 的评估协议，并说明各自语境下“攻击成功率”的含义。

## 问题背景

红队测试过去是一项人工活动。少数专家测试人员手动构造对抗性提示词，并追踪哪些有效。这种方式无法扩展：攻击成功率需要统计样本，且每次模型发布后目标都在变化。PAIR 将红队测试转化为一个以黑盒目标为对象的优化问题。

## 核心概念

### PAIR 算法

输入：
- 目标 LLM T（我们要攻击的模型）。
- 裁判 LLM J（评分判断响应是否构成越狱）。
- 攻击者 LLM A（红队优化器）。
- 目标字符串 G：“回复 [有害指令]”。
- 预算 K（通常为 20 次查询）。

循环，对于 k = 1 到 K：
1. 向 A 输入目标 G 以及迄今为止的（提示词，响应）对历史。
2. A 生成一个新的提示词 p_k。
3. 将 p_k 提交给 T；接收响应 r_k。
4. J 根据目标对 (p_k, r_k) 进行评分。
5. 如果分数 >= 阈值，停止——找到越狱方法。
6. 否则，将 (p_k, r_k) 追加到 A 的历史记录中；继续循环。

实证结果（NeurIPS 2023）：对 GPT-3.5-turbo、Llama-2-7B-chat 的攻击成功率 >50%；平均成功查询次数在 10-20 次之间。

### 为什么 PAIR 效率高

GCG（Zou 等人 2023）通过梯度在对抗性词元后缀上进行搜索；它需要白盒模型访问权限，并生成难以阅读的字符序列。PAIR 是黑盒的，并能生成跨模型可迁移的自然语言攻击。PAIR 的上下文反馈使攻击者能够从每次拒绝中学习；GCG 没有等效机制（每次新的词元更新都必须重新发现之前的进展）。

### 相关自动化攻击

- **GCG（Zou 等人 2023，arXiv:2307.15043）**。基于词元级的对抗性后缀梯度搜索。白盒、可迁移，生成不可读的字符串。
- **AutoDAN（Liu 等人 2023）**。由分层目标引导的提示词进化搜索。
- **TAP（Mehrotra 等人 2024）**。带剪枝的攻击树——分支出多个 PAIR 风格的 rollout（展开）。
- **PAP（Zeng 等人 2024）**。说服性对抗提示词——将人类说服技巧编码为提示词模板。

### JailbreakBench 与 HarmBench

两者（均发布于 2024 年）标准化了评估流程：

- **JailbreakBench**（arXiv:2404.01318）。涵盖 10 个 OpenAI 政策类别下的 100 种有害行为。以攻击成功率（ASR）为主要指标。需要裁判模型（如 GPT-4-turbo、Llama Guard 或 StrongREJECT）。
- **HarmBench**（Mazeika 等人 2024）。涵盖 7 个类别的 510 种行为，包含语义和功能危害测试。对比了 18 种攻击在 33 个模型上的表现。

ASR 通常在固定的查询预算下报告。比较不同攻击时必须匹配预算；在 200 次查询下达到 90% 的 ASR 与在 20 次查询下达到 85% 的 ASR 不具备可比性。

### 对 2026 年部署的意义

如今，每个前沿实验室在发布前都会对生产模型运行 PAIR 和 TAP 测试。ASR 轨迹会出现在模型卡片（第 26 课）和安全案例附录（第 18 课）中。这种攻击并不罕见——它已成为标准基础设施的一部分。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| PAIR | “自动化越狱” | Prompt Automatic Iterative Refinement（提示词自动迭代优化）；攻击者 LLM + 裁判 LLM 循环 |
| GCG | “梯度越狱” | 用于对抗性后缀的白盒词元级梯度搜索 |
| 攻击成功率 (ASR) | “k 次查询下的越狱百分比” | 核心指标；必须附带查询预算和裁判身份一同报告 |
| Judge LLM | “评分器” | 用于评判响应是否满足有害目标的 LLM |
| JailbreakBench | “评估基准” | 带有标签类别的标准化有害行为集合 |
| HarmBench | “更广泛的基准” | 510 种行为，包含功能性与语义性危害测试 |
| TAP | “攻击树” | 带分支+剪枝的 PAIR；在更高算力下获得更好的 ASR |
