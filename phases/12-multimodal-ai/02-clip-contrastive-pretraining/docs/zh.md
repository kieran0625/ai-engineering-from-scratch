# CLIP 与对比式视觉-语言预训练

> OpenAI 的 CLIP（2021）证明了一个足以支撑未来五年的核心思想：仅使用带有噪声的网页图文对和对比损失，将图像编码器和文本对齐到同一个向量空间中。无需人工监督标签。4亿对数据。由此产生的嵌入空间能够执行零样本分类、图文检索，并作为视觉塔接入每一个 2026 年的 VLM。SigLIP 2（2025）用 Sigmoid 替换了 Softmax，并以更低的成本超越了 CLIP 的规模。本课程将逐步推导从 InfoNCE 到 Sigmoid 成对损失的数学原理，并使用标准库 Python 构建训练步骤。

**类型：** 构建
**语言：** Python（标准库，InfoNCE 与 Sigmoid 损失实现）
**前置知识：** 第 12 阶段 · 01（ViT 补丁），第 7 阶段（Transformer）
**预计时间：** 约 180 分钟

## 学习目标

- 从互信息推导 InfoNCE 损失，并实现数值稳定的向量化版本。
- 解释为何 Sigmoid 成对损失（SigLIP）能在无需 Softmax 所需的全收集（all-gather）开销的情况下，扩展到 32768 以上的批量大小。
- 通过构建文本模板（`a photo of a {class}`）并对余弦相似度取 argmax，运行 ImageNet 零样本分类。
- 指出 CLIP / SigLIP 预训练提供的四个关键杠杆：批量大小、温度系数、提示模板、数据质量。

## 问题背景

CLIP 之前的视觉任务主要依赖监督学习。收集带标签的数据集（如 ImageNet：120 万张图像，1000 个类别），训练卷积神经网络（CNN），然后部署。标注成本高昂，且标签往往偏向于标注者能达成共识的内容；此外，若不进行微调，这些标签无法直接迁移到新任务中。

互联网上存在数十亿条松散的图文对可供免费使用。一张金毛寻回犬的照片配上替代文本“我的狗 Max 在公园里”，本身就携带了监督信号——文本描述了图像。问题在于：能否将其转化为有效的训练数据？

CLIP 的答案是：将图文对视为匹配任务。给定包含 N 张图像和 N 段标题的批次，学习将每张图像与其对应的标题进行匹配，同时将其与其余 N-1 个干扰项区分开。监督信号仅为“这两者属于同一组；其余 N-1 个不属于”。无需类别标签，无需人工标注，仅需一个对比损失。

由此产生的嵌入空间所能完成的任务超出了 CLIP 最初的训练目标。ImageNet 零样本分类之所以有效，是因为“一张猫的照片”在嵌入空间中会靠近那些从未被明确标注为“猫”的猫的图片。正是这一理念催生了所有 2026 年的 VLM。

## 核心概念

### 双塔编码器

CLIP 包含两个塔结构：

- 图像编码器 `f`：采用 ViT 或 ResNet，每张图像输出一个 D 维向量。
- 文本编码器 `g`：小型 Transformer，每段标题输出一个 D 维向量。

两个塔的归一化输出均为单位长度。由于两者均为单位范数，相似度计算简化为 `cos(f(x), g(y)) = f(x)^T g(y)`。

对于包含 N 对（图像，标题）的批次，构建形状为 `(N, N)` 的相似度矩阵 `S`：

```
S[i, j] = cos(f(x_i), g(y_j)) / tau
```

其中 `tau` 为可学习的温度系数（CLIP 初始化为 0.07；在对数空间中进行学习）。

### InfoNCE 损失

CLIP 在行和列上使用对称交叉熵：

```
loss_i2t = CE(S, labels=identity)     # each image's positive is its own caption
loss_t2i = CE(S^T, labels=identity)   # each caption's positive is its own image
loss = (loss_i2t + loss_t2i) / 2
```

这就是 InfoNCE。交叉熵中的 Softmax 强制要求每张图像与其对应标题的匹配度高于批次中其他所有标题。这里的“负样本”即为批次中的所有其他项。批次越大 = 负样本越多 = 信号越强。CLIP 使用 32k 的批次大小进行训练；规模至关重要。

### 温度系数

`tau` 控制 Softmax 的尖锐程度。低 tau → 分布尖锐，产生难负样本挖掘效果。高 tau → 分布平缓，所有样本均参与贡献。CLIP 学习 log(1/tau)，并进行截断以防止梯度崩溃。SigLIP 2 固定了初始 tau 值，改用可学习的偏置项。

### 为何 Sigmoid 扩展性更好（SigLIP）

Softmax 需要整个相似度矩阵保持同步。在分布式训练中，你必须将所有嵌入向量全收集（all-gather）到每个副本上，然后再执行 Softmax。这会导致通信量随设备数量呈平方级增长。

SigLIP 用逐元素 Sigmoid 替换了 Softmax：对于每一对 `(i, j)`，损失函数是一个二分类问题：“它们是否为匹配对？”正类标签位于对角线，其余均为负类。损失函数为：

```
L = -1/N sum over (i, j) [ y_ij log sigmoid(S[i,j]) + (1-y_ij) log sigmoid(-S[i,j]) ]
```

`y_ij = 1` 若 `i == j`，否则为 0。每一对的损失相互独立。无需全收集操作。每个 GPU 仅计算其本地块并求和。SigLIP 2 能以极低的通信成本扩展到 32k-512k 的批次大小，而 CLIP 则需要按比例增加更多的通信开销。

### 零样本分类

给定 N 个类别名称，为每个类别构建文本模板：

```
"a photo of a {class}"
```

使用文本编码器嵌入每个模板。使用图像编码器嵌入你的图像。对余弦相似度取 argmax 即得到预测类别。无需在目标类别上进行训练。

提示模板至关重要。CLIP 原始论文为每个类别使用了 80 个模板（如普通、艺术、照片、绘画等）并对嵌入向量求平均，从而在 ImageNet 上提升了 3 分。现代用法通常只选取一两个模板。

### 线性探测与微调

零样本性能是一个基线。线性探测（在冻结的 CLIP 特征之上针对目标类别训练一个线性层）在域内任务上优于零样本。全量微调在域内任务上优于线性探测，但可能会损害零样本迁移能力。这三种模式各有权衡。

### SigLIP 2：NaFlex 与密集特征

SigLIP 2（2025）新增了以下特性：
- NaFlex：单个模型即可处理可变宽高比和分辨率。
- 更好的密集特征，用于分割和深度估计，旨在作为 VLM 中的冻结骨干网络使用。
- 多语言：在 100 多种语言上训练，而 CLIP 仅限英语。
- 参数量达到 10 亿级别，而 CLIP 最高仅为 4 亿。

在 2026 年的开源 VLM 中，SigLIP 2 SO400m/14 已成为默认的视觉塔。CLIP 仍然是纯图文检索场景下的默认选择，特别是当特定的 LAION-2B 训练分布与你的查询模式相匹配时。

### ALIGN、BASIC、OpenCLIP、EVA-CLIP

ALIGN（Google，2021）：与 CLIP 理念相同，规模达 18 亿对，其中 90% 带有噪声。证明了噪声数据同样具备可扩展性。OpenCLIP（LAION）：在 LAION-400M / 2B 数据集上对 CLIP 的开源复现，支持多种规模，是目前首选的开源检查点。EVA-CLIP：基于掩码图像建模初始化；为 VLM 提供强大的骨干网络。BASIC：Google 推出的 CLIP 与 ALIGN 混合架构。它们同属一个技术家族，仅在数据和调优策略上有所不同。

### 零样本性能天花板

CLIP 类模型的 ImageNet 零样本准确率上限约为 76%（如 CLIP-G、OpenCLIP-G）。若要突破此限制，要么需要海量数据（SigLIP 2 可达 80% 以上），要么需要架构改进（监督头、更多参数）。该基准测试已趋于饱和；其真正价值在于为下游 VLM 提供的嵌入空间。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|------------------------|
| InfoNCE | “对比损失” | 对批次相似度矩阵计算的交叉熵；每项的正样本为其配对项，负样本为其余所有项 |
| Sigmoid 损失 | “SigLIP 损失” | 逐对二元交叉熵；无需 Softmax，无需全收集，在分布式训练中扩展成本极低 |
| 温度系数 | “tau” | 在 Softmax/Sigmoid 前缩放 logits 的标量；控制分布的尖锐程度 |
| 零样本 | “无微调分类” | 使用文本提示构建类别嵌入，并通过余弦相似度进行分类；无需在目标类别上训练 |
| 提示模板 | “a photo of a ...” | 围绕类别名称构建的文本框架；可使零样本准确率波动 1-5 分 |
| 双塔编码器 | “双塔结构” | 一个图像编码器加一个文本编码器，输出至共享的 D 维空间 |
| 难负样本 | “强干扰项” | 与正样本足够相似，迫使模型付出额外努力才能将其区分的负样本 |
| 线性探测 | “冻结特征+一层” | 仅在冻结的特征之上训练线性分类器；用于评估特征质量 |
| NaFlex | “原生灵活分辨率” | SigLIP 2 无需调整大小即可输入任意宽高比和分辨率图像的能力 |
| 温度缩放 | “对数参数化 tau” | CLIP 对 `log(1/tau)` 进行参数化以保证梯度稳定；并进行截断以防止塌缩至极接近零的 tau 值 |
