# 开放权重 VLM 食谱：真正关键的是什么

> 2024-2026 年的开放权重 VLM 文献是一片消融实验表格的森林。Apple 的 MM1 测试了图像编码器、连接器（connector）和数据混合比例的 13 种组合。Allen AI 的 Molmo 证明了详细的人类标注字幕优于 GPT-4V 蒸馏数据。Cambrian-1 进行了 20 多种编码器的对比。Idefics2 形式化了五轴设计空间。Prismatic VLMs 在受控基准上比较了 27 种训练配方。在这些繁杂的信息中，有一组结果在各篇论文中普遍成立：图像编码器比连接器架构更重要，数据混合比例比两者都重要，而详细的人类标注字幕优于蒸馏生成的合成数据。本课程将为你解读这些表格，让你无需亲自翻阅。

**类型：** 学习 + 实验
**语言：** Python（标准库、消融表格解析器 + 配方选择器）
**前置要求：** 第 12 阶段 · 05（LLaVA 基线）
**耗时：** 约 180 分钟

## 学习目标

- 说出 VLM 的五轴设计空间：图像编码器、连接器、大语言模型（LLM）、数据混合、分辨率调度。
- 阅读 MM1 / Idefics2 / Cambrian-1 的消融表格，并预测哪个参数调整会影响特定基准测试的成绩。
- 给定算力预算和任务组合，为新的 VLM 选择合适的配方（编码器、连接器、数据、分辨率）。
- 解释为什么在相同 token 数量下，详细的人类标注字幕能胜过 GPT-4V 蒸馏数据。

## 问题背景

目前已有数百个开放权重的 VLM。大多数“良好”与“最先进（SOTA）”之间的差距并非来自架构，而是数据、分辨率调度和编码器选择。当模型表现不佳时，知道该优先调整哪个参数，能帮你避免浪费数百万 GPU 小时的错误尝试。

2023 年的浪潮（LLaVA-1.5、InstructBLIP、MiniGPT-4）基于字幕对预训练 + LLaVA-Instruct-150k。这是一个不错的基线，但在 MMMU 上的成绩止步于 35% 左右。

2024 年的浪潮（MM1、Idefics2、Molmo、Cambrian-1、Prismatic VLMs）进行了详尽的消融实验。结果既出人意料又极具实用价值。

## 核心概念

### 五轴设计空间

Idefics2（Laurençon 等人，2024）明确了这五个维度：

1. 图像编码器。CLIP ViT-L/14、SigLIP SO400m/14、DINOv2 ViT-g/14、InternViT-6B。不同编码器在补丁大小（patch size）、分辨率和预训练目标上存在差异。
2. 连接器。MLP（2-4 层）、Q-Former（32 个查询向量 + 交叉注意力）、Perceiver Resampler（64 个查询向量）、C-Abstractor（卷积 + 双线性池化）。
3. 语言模型。Llama-3 8B / 70B、Mistral 7B、Phi-3、Gemma-2、Qwen2.5。LLM 的参数量是主要的计算成本来源。
4. 训练数据。字幕对（CC3M、LAION）、交错数据（OBELICS、MMC4）、指令数据（LLaVA-Instruct、ShareGPT4V、PixMo、Cauldron）。
5. 分辨率调度。固定 224/336/448、AnyRes、原生动态。训练中逐步提升或保持恒定。

每个生产级 VLM 都会在这五个维度上做出选择。MMMU 分数的绝大部分差异可由维度 1、4 和 5 解释——而不是取决于你选择了哪种连接器。

### 维度 1：编码器 > 连接器

MM1 第 3.2 节显示：将 CLIP ViT-L/14 替换为 SigLIP SO400m/14 可使 MMMU 提升 3 分以上。而将连接器从 MLP 替换为 Perceiver Resampler 仅提升不到 1 分。Idefics2 验证了这一结论：SigLIP > CLIP，且在相同 token 数量下 Q-Former ≈ MLP ≈ Perceiver。

Cambrian-1 的“Cambrian Vision Encoders Match-Up”（Tong 等人，2024）在视觉主导型基准（CV-Bench）上运行了 20 多种编码器。排行榜前列是 DINOv2 和 SigLIP 的组合；CLIP 处于中游；ImageBind 和 ViT-MAE 排名较低。在 CV-Bench 上，从 CLIP ViT-L 到 DINOv2 ViT-g/14 的差距约为 5-7 分。

2026 年开放 VLM 的默认编码器是 SigLIP 2 SO400m/14（用于语义和密集特征），有时会与 DINOv2 ViT-g/14 的特征拼接（Cambrian 的“Spatial Vision Aggregator”正是采用此做法）。

### 维度 2：连接器设计差异不大

MM1、Idefics2、Prismatic 和 MM-Interleaved 都得出了相同的结论：在固定的视觉 token 数量下，连接器架构的影响微乎其微。在相同的 token 预算下，作用于平均池化补丁的 2 层 MLP 性能与 32 查询的 Q-Former 相差不到 1 分。

真正重要的是 token 数量。更多的视觉 token = 更多的 LLM 计算量 = 更好的性能（直到某一点后收益递减）。每张图 64 个 token 对于 OCR 来说太少了。576-1024 个 token 是大多数开放 VLM 的最佳区间。2048+ 仅在文档和图表场景中有用。

Q-Former 与 MLP 的选择是成本问题而非质量问题：Q-Former 无论图像分辨率如何都将 token 限制在 32-64 个；MLP 则输出所有补丁 token。对于高分辨率输入，Q-Former 能节省 LLM 的上下文窗口；对于低分辨率输入，两者的差异只是噪声。

### 维度 3：LLM 规模决定上限

将 LLM 从 7B 翻倍至 13B，在所有 VLM 论文中都能稳定使 MMMU 提升 2-4 分。达到 70B 时，你已能跑满大多数基准测试。VLM 的多模态推理上限就是 LLM 的文本推理上限——视觉编码器只能提供信息，无法替它进行推理。

这就是为什么 Qwen2.5-VL-72B 和 Claude Opus 4.7 能在 MMMU-Pro 和 ScreenSpot-Pro 上取得压倒性优势：语言模型的大脑足够庞大。一个 7B 的 VLM 无法通过巧妙的连接器设计来替代 70B 的 VLM。

### 维度 4：数据——详细人类字幕胜过蒸馏

Molmo + PixMo（Deitke 等人，2024）是 2024 年每位研究者都应阅读的论文。Allen AI 安排人类标注员以 1-3 分钟的密集语音转文字方式描述图像，生成了 71.2 万张密集标注图像。训练数据中完全没有使用 GPT-4V 蒸馏。

Molmo-72B 在 11 项基准测试中的 11 项上击败了 Llama-3.2-90B-Vision。差距不在架构，而在字幕质量。详细的人类字幕每张图包含的信息量是简短网络字幕的 5-10 倍，并且在 GPT-4V 蒸馏容易产生幻觉的地方保持了事实准确性。

ShareGPT4V（Chen 等人，2023）和 Cauldron（Idefics2）遵循了相同的策略，采用混合人类 + GPT-4V 字幕。趋势很明确：面向 2026 年的前沿技术，字幕密度 > 字幕数量 > 蒸馏便利性。

### 维度 5：分辨率及其调度

Idefics2 的消融实验显示：384 -> 448 可提升 1-2 分。配合图像切分的 448 -> 980（AnyRes）可在 OCR 基准上再提升 3-5 分。固定分辨率训练会在中等准确率处进入平台期；分辨率逐步提升（从 224 开始，最终达到 448 或原生分辨率）训练速度更快且最终成绩更高。

Cambrian-1 进行了分辨率与 token 数量的权衡实验：在固定算力下，你可以选择低分辨率更多 token，或高分辨率更少 token。OCR 场景高分辨率胜出；通用场景理解则是低分辨率多 token 胜出。

2026 年的生产级配方：Stage 1 固定 384 训练，Stage 2 针对重度 OCR 任务使用最高达 1280 的动态分辨率。

### Prismatic 的受控对比

Prismatic VLMs（Karamcheti 等人，2024）是严格控制了所有维度的论文。使用相同的 13B LLM、相同的指令数据和相同的评估方法——每次仅改变一个维度。结果如下：

- 单图视觉 token 数量解释了约 60% 的性能方差。
- 编码器选择解释了约 20%。
- 连接器架构解释了约 5%。
- 其他所有因素（数据混合、调度器、学习率）占剩余的约 15%。

这是一种粗略的分解，但它是文献中对“我应该首先消融哪个维度”最清晰的答案。

### 2026 年配方选择器

基于现有证据，2026 年新项目的默认开放 VLM 配方如下：

- 编码器：原生分辨率下的 SigLIP 2 SO400m/14（配合 NaFlex），若需要分割/定位任务，则拼接 DINOv2 ViT-g/14 特征。
- 连接器：作用于补丁 token 的 2 层 MLP。除非受限于 token 数量，否则跳过 Q-Former。
- LLM：Qwen2.5 / Llama-3.1 / Gemma 2，7B 侧重成本，70B 侧重质量，根据目标延迟进行选择。
- 数据：PixMo + ShareGPT4V + Cauldron，并根据任务补充特定指令数据。
- 分辨率：动态（短边最小 256，长边最大 1280 像素）。
- 调度：Stage 1 对齐（仅训练投影层），Stage 2 全量微调，Stage 3 任务特定微调。

上述每一项默认设置均可追溯至本课末尾引用论文中的实测消融实验。

## 实践应用

`code/main.py` 是一个消融表格解析器和配方选择器。它内置了 MM1 和 Idefics2 的消融表格（精简版），并支持以下查询：

- “给定预算 X 和任务 Y，什么配方最优？”
- “如果在 7B Llama 上将 SigLIP 替换为 CLIP，预期的 MMMU 变化是多少？”
- “为了获得 80% 置信度的答案，我应该首先消融哪个维度？”

输出结果为按优先级排序的配方列表，包含预期的基准分数变化以及“优先消融”建议。

## 交付成果

本课程将产出 `outputs/skill-vlm-recipe-picker.md`。给定目标任务组合、算力预算和延迟目标，它将生成完整的配方（编码器、连接器、LLM、数据混合、分辨率调度），并为每项选择附上支撑其的消融实验引用。这将防止工程师在新 VLM 项目启动时重复造轮子去重做 Idefics2 的消融实验。

## 练习

1. 阅读 MM1 第 3.2 节。对于固定 2B LLM 且预算为 5000 万张图像的情况，哪种编码器胜出？如果换成 13B LLM，答案会反转吗？为什么？

2. Cambrian-1 发现，在视觉主导型基准上拼接 DINOv2 + SigLIP 优于单独使用任一模型，但在 MMMU 上未带来额外提升。请预测哪些基准会受益，哪些会保持平稳。

3. 你的目标是基于 2B LLM 构建移动端 UI 智能体。请选择编码器、连接器、分辨率和数据混合方案，并用具体的消融表格为每项选择提供依据。

4. Molmo 发布了 4B 和 72B 模型。4B 版本可与闭源 7B VLM 竞争；72B 版本在 11/11 项基准上击败 Llama-3.2-90B-Vision。这对“LLM 规模平台期假说”说明了什么？

5. 设计一个消融表格，以便在 7B VLM 上将数据混合质量与编码器质量隔离开来。至少需要多少次训练运行？请提出四个维度的设置方案。

## 核心术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| Ablation | “调节单一旋钮” | 控制其他变量不变，仅在设计空间的一个维度上进行差异化的多次训练运行 |
| Connector | “桥梁” / “投影层” | 可训练模块，负责将视觉编码器输出映射到大语言模型的 token 空间（如 MLP、Q-Former、Perceiver） |
| Detailed human caption | “密集字幕” | 由人工撰写的多句描述（通常为 80-300 个 token），信息量远超网页 alt text |
| Distillation | “GPT-4V 字幕” | 由更强的闭源 VLM 生成的训练数据；虽方便但容易继承幻觉 |
| AnyRes / dynamic res | “高分路径” | 通过图像分块或 M-RoPE 等技术，向编码器输入超过其原生分辨率图像的机制 |
| Resolution ramp | “课程学习” | 从低分辨率开始训练并逐步提升的调度策略，可加速对齐学习过程 |
| Vision-centric bench | “CV-Bench / BLINK” | 侧重细粒度视觉感知而非重度语言推理的评估体系 |
| PixMo | “Molmo 的数据集” | Allen AI 的 71.2 万张密集标注图像数据集；将人类语音转录为密集字幕 |
