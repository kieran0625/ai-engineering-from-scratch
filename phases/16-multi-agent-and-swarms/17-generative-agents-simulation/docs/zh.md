# 生成式智能体与涌现模拟

> Park 等人（2023，UIST '23，arXiv:2304.03442）在包含 25 个智能体的沙盒 **Smallville** 中部署了三部分架构：**记忆流**（自然语言日志）、**反思**（智能体针对自身记忆流生成的更高层级综合内容）和**规划**（日级行为及其子规划）。标志性成果是情人节派对的涌现：一个被植入“想要举办情人节派对”目标的智能体，在没有额外脚本的情况下，促成了邀请函在群体中的传播、约会时间的协调，最终派对如期举行——而最初有 24 个智能体对此一无所知。消融实验表明，这三个组件对于拟真度缺一不可。文档记录的主要失败案例包括空间规范错误（进入已关闭的商店、共用单人卫生间等）。这是 2026 年智能体模拟与多智能体社会评估的参考架构。

**类型：** 学习 + 构建
**语言：** Python (stdlib)
**前置要求：** 第 16 阶段 · 04（基础模型），第 16 阶段 · 13（共享记忆）
**耗时：** ~75 分钟

## 问题

大多数多智能体系统是强脚本化的团队：规划者制定计划，编码者编写代码，审查者进行审查。这在定义明确的任务上有效，但无法捕捉当智能体拥有记忆、优先级和开放世界时所产生的涌现式、非脚本化行为。研究、社会模拟以及日益增长的游戏 AI 都需要这种第二类的系统。

Smallville 架构是其基准。在 Park 2023 之前，最好的智能体模拟只是浅层的脚本跟随者；在此之后，该模式已成为开放世界中生成式智能体的默认范式。如果你在 2026 年构建智能体模拟，你要么使用 Smallville 的三个组件，要么必须明确说明为何不采用。

## 概念

### 三大核心组件

**记忆流。** 仅追加的观察、行动、反思和规划日志。每条记录包含时间戳、类型、描述（自然语言）以及衍生元数据：**近期度**、**重要性**（智能体自评 1-10 分）和**相关性**（与当前查询的余弦相似度）。

```
[2026-02-14 09:12:03] observation: Isabella Rodriguez asked me if I like jazz
[2026-02-14 09:14:22] reflection:   I enjoy long conversations about music
[2026-02-14 10:05:00] plan:         Attend Isabella's Valentine's Day party tonight
```

记忆检索结合这三个分数：`score = w_recency * e^(-decay * age) + w_importance * importance + w_relevance * cos_sim`。得分最高的 Top-k 条目将进入当前提示词。

**反思。** 定期（每 N 条记忆或遇到重要事件时），智能体会基于近期记忆生成高阶综合内容。反思条目会重新写入记忆流，并可像其他记忆一样被检索。这是智能体构建“理解力”的方式——相当于架构中的长期信念。

**规划。** 自上而下的分解。首先制定日级宏观计划（“去上班，与 Klaus 共进晚餐”），然后是小时级计划，最后是行动级计划。规划是可修订的：当新观察与计划冲突时，智能体会仅重规划受影响的片段。

### 为何三者缺一不可（消融实验）

Park 等人进行了消融实验，分别移除观察、反思和规划模块。每个消融都会损害拟真度：

- 缺少**观察**会导致智能体脱离上下文，基于过时信念行动。
- 缺少**反思**会使智能体无法形成高阶信念；交互停留在表面。
- 缺少**规划**会导致行为沦为反应性噪声；目标随之消散。

人类评估者的拟真度评分在三项俱全时最高；缺失任何一项都会导致可测量的性能退化。

### 情人节派对的涌现现象

一个名为 Isabella Rodriguez 的智能体被植入目标：“想要在 2 月 14 日下午 5 点在 Hobbs Cafe 举办情人节派对。”其余 24 个智能体未接收此种子目标。在模拟天数推进过程中：

1. Isabella 的计划包含邀请他人。
2. 每次邀请都成为邻居记忆流中的一条观察记录。
3. 邻居的反思机制生成信念：“Isabella 正在举办派对。”
4. 邻居的计划纳入“参加 2 月 14 日的派对”。
5. 邻居告知其他邻居。邀请在无中央协调的情况下扩散。
6. 2 月 14 日下午 5 点，多个智能体汇聚到 Hobbs Cafe。

这在技术意义上属于涌现：系统级行为（一场派对）源于局部交互（双边邀请 + 个体规划），无需中央协调器。

### 已记录的失败模式

Park 等人明确记录了以下问题：

- **空间规范错误。** 智能体会走进已关闭的商店。智能体会尝试共用同一个单人卫生间。智能体会在不适合用餐的房间进食。模型无法仅从环境中推断社会物理规范。
- **记忆溢出。** 深度模拟运行会导致记忆检索成本增长。实际解决方案：定期记忆压缩（摘要与剪枝）以及对低重要性条目的衰减处理。
- **反思幻觉。** 反思可能会编造记忆流中不存在的关联关系。缓解措施：在反思提示词中包含源记忆 ID，并在检索时进行验证。

这些是与生产环境相关的失败模式：任何 2026 年的智能体模拟都会继承这些问题。

### 三组件实现规则

1. **记忆仅追加。** 绝不修改现有记忆条目。修正通过新增条目完成。
2. **重要性评分成本低。** 在写入时调用 LLM 对重要性进行 1-10 分评级。缓存该分数。
3. **检索按排名而非过滤。** 按综合得分取 Top-k；避免使用硬过滤（这会丢失上下文）。
4. **反思定期运行。** 当未处理记忆的重要性总和超过阈值（例如 150）时触发。
5. **规划可修订。** 当新观察与计划冲突时，仅重新生成受影响片段，而非整个计划。

### Smallville 之外的生成式智能体

2024-2026 年的后续文献扩展了该架构：

- **政策/市场调研的多智能体社会模拟。** 类 Smallville 的人口模拟用户对新功能的响应行为。比 A/B tests 更快；准确性存在争议。
- **游戏的 NPC AI。** 搭载 Smallville 智能体的 RPG 会产生涌现式剧情线，而非预设任务。
- **生成式智能体评估基准。** 指标从任务准确率转变为长周期运行的行为拟真度与连贯性。

该架构是参考标准。扩展方案会替换组件（如用向量存储替代记忆、检索增强反思、神经符号规划），但保留三部分结构。

### 为何这对多智能体工程至关重要

Smallville 证明了当组件设计得当，多智能体涌现的成本是可控的。该架构现已在开源模型上复现（较小规模的 LLM 会平滑地降低拟真度，而非断崖式下跌）。任何需要**涌现式社会行为**的生产系统均采用此形态。任何需要**严格任务执行**的系统则使用本阶段早期介绍的 supervisor / roles / primitives 模式。

## 动手构建

`code/main.py` 使用 stdlib Python 实现了三大组件，并采用脚本化智能体策略（无真实 LLM）。该演示以微缩规模复现了情人节派对的涌现现象：

- `MemoryStream` —— 支持近期度/重要性/相关性检索的仅追加日志。
- `reflect(stream)` —— 基于近期高重要性记忆的脚本化反思。
- `plan(agent_state)` —— 基于当前信念的日级与小时级规划。
- 场景：5 个智能体。智能体 1 初始目标为“下午 5 点举办派对”。随着模拟刻度推进，邀请扩散，智能体逐渐汇聚。

运行：

```
python3 code/main.py
```

预期输出：逐刻度追踪日志。到最后一个刻度时，5 个智能体中至少有 3 个在其计划中显示派对，且它们汇聚到了派对地点。单一种子目标在无协调器的情况下促成了协同到达。

## 实际应用

`outputs/skill-simulation-designer.md` 用于设计生成式智能体模拟：设定智能体数量、记忆模式、反思频率、规划时间跨度及评估指标。

## 生产部署

生产环境模拟规则：

- **记忆即数据库。** 规模化时选择真实存储（Vector DB、Postgres）。内存中的 stdlib 仅用于原型开发。
- **记录检索追踪日志。** 对每次行动，记录驱动它的 Top-k 记忆。这是你的调试能力所在。
- **控制单智能体 Token 预算。** 每个智能体每刻度的 retrieve + reflect + plan 涉及 O(k) 次 LLM 调用。N agents × T ticks × calls-per-tick 可能远超你的预算。
- **定期压缩记忆。** 对低重要性条目进行摘要与剪枝。Retention policy 是设计决策，而非细节。
- **显式检测空间/社会规范违规。** 该架构不会自动学习这些规范。

## 练习

1. 运行 `code/main.py`。确认 3 个及以上智能体在派对处汇聚。将智能体数量增至 10 个——涌现现象是否依然发生？
2. 移除反思步骤。行为表现如何？对照 Park 2023 中的消融实验结论进行分析。
3. 引入竞争性种子目标（“Klaus 想在下午 5 点进行学术演讲”）。智能体会分裂，还是某一目标占主导？由什么因素决定？
4. 添加空间约束：Hobbs Cafe 最多容纳 4 个智能体。模拟能否优雅处理溢出，还是会陷入“单人卫生间”式的失败模式？
5. 阅读 Park 等人（arXiv:2304.03442）第 6 节（涌现行为实验）。找出一个在你的微缩模拟中无法复现的行为。你需要增强架构的哪个组件？

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| Memory stream | “智能体的日记” | 仅追加的观察、行动、反思与规划日志。 |
| Recency | “记忆有多新” | 基于年龄的指数衰减评分。 |
| Importance | “智能体有多在意” | 写入时自评 1-10 分。已缓存。 |
| Relevance | “与当前查询的相关程度” | 基于嵌入的余弦相似度。 |
| Reflection | “高阶信念” | 基于近期记忆生成的综合内容，作为新记忆重新注入。 |
| Plan | “日/小时/行动分解” | 自上而下的规划树。当观察与计划冲突时可修订。 |
| Smallville | “Park 2023 的沙盒” | 产生情人节涌现现象的 25 智能体模拟环境。 |
| Believability | “质量指标” | 人类评估者打分，衡量行为是否像一个合理的智能体。 |
