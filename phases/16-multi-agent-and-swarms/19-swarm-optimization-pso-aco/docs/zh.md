# 面向大语言模型的群体智能优化（PSO、ACO）

> 生物启发式优化正在大语言模型领域迎来复兴。**LMPSO** (arXiv:2504.09247) 使用 PSO，其中每个粒子的速度是一个提示词（prompt），LLM 生成下一个候选解；在结构化序列输出（数学表达式、程序）上表现良好。**Model Swarms** (arXiv:2410.11163) 将每个 LLM 专家视为模型权重流形上的 PSO 粒子，仅在 200 个实例下，就在 9 个数据集的 12 个基线方法上实现了平均 **13.3% 的提升**。**SwarmPrompt** (ICAART 2025) 混合了 PSO 与灰狼算法用于提示词优化。**AMRO-S** (arXiv:2603.12933) 是受 ACO 启发的信息素专家，用于多智能体 LLM 路由——实现 **4.7 倍加速**，提供可解释的路由证据，并采用质量门控异步更新机制，将推理与学习解耦。本课将在提示词参数空间上实现 PSO，在智能体路由上实现 ACO，测量这些经典算法为何契合 LLM 时代，以及何时不适用。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置知识：** Phase 16 · 09（并行群体网络）、Phase 16 · 14（共识与 BFT）
**耗时：** 约 75 分钟

## 问题

你有一个在任务评估中得分 62% 的提示词。你想改进它。最直观的做法是进行无梯度的手动调优，但这很难扩展。强化学习需要奖励信号和足够的 rollout 来训练。通过提示词进行反向传播实际上并不可行——提示词是一个离散字符串，而不是可微参数。

经典的生物启发式优化算法——用于连续搜索空间的 PSO 和用于路径选择的 ACO——正是为这种场景设计的：无梯度、基于种群、单次评估成本低。将它们与 LLM 结合用于无梯度搜索步骤，你会得到一个出人意料的实用优化器。

同样的模式也适用于多智能体系统中的智能体*路由*。ACO 风格的信息素轨迹记录了哪种智能体在哪些任务类型上表现最佳，让路由器能够利用该轨迹，并通过信息素衰减使路由能够被重新发现。

## 概念

### PSO 回顾（Kennedy & Eberhart 1995）

粒子群优化：在连续搜索空间中维护一个粒子种群。每个粒子具有位置 `x_i` 和速度 `v_i`。每次迭代执行以下操作：

```
v_i <- w * v_i + c1 * r1 * (p_best_i - x_i) + c2 * r2 * (g_best - x_i)
x_i <- x_i + v_i
evaluate fitness(x_i)
update p_best_i if improved
update g_best if global best
```

其中 `p_best` 是粒子自身的历史最优，`g_best` 是整个种群的当前最优，`w, c1, c2` 是惯性、认知和社会权重，`r1, r2` 是随机因子。

### LLM 输出上的 PSO —— LMPSO

arXiv:2504.09247 将 PSO 适配于 LLM 生成的结构化输出（数学表达式、程序）。每个粒子是一个候选输出。速度是一个*提示词*，描述如何将当前输出向个人/全局最优方向修改。LLM 根据速度提示词生成新输出。速度的“惯性”体现为类似“进行微小的增量修改”的提示词。

在以下情况下效果良好：
- 输出是结构化的（可解析、可评估）。
- 适应度函数是自动的（测试运行、算术评估）。
- 种群规模较小（约 10-30 个粒子），从而使 LLM 调用总量保持在可控范围内。

当适应度需要人工审核时效果不佳——因为每次迭代的成本会变得难以承受。

### Model Swarms

arXiv:2410.11163 将 PSO 从输出层移至*模型*层。每个“粒子”是一个专家 LLM（参数）。群体通过无梯度更新将参数向集体最优方向移动。据报道：在 9 个数据集上，仅使用每轮 200 个实例，就在 12 个基线方法上取得了平均 13.3% 的提升。

关键洞察在于，LLM 专家模型在共享的参数流形上已经彼此接近（适配器权重、LoRA 增量）。在此低维子空间上运行 PSO 成本低且高效。

### ACO 回顾（Dorigo 1992）

蚁群优化：蚂蚁遍历图结构；每条路径都有一条信息素轨迹。蚂蚁的移动概率由信息素强度加权。完成任务的蚂蚁会根据解的质量沉积相应比例的信息素。信息素会随时间衰减。

### AMRO-S —— 用于智能体路由的 ACO

arXiv:2603.12933 使用 ACO 进行多智能体路由。每种任务类型是一个“目的地”；每个智能体是一条可能的路由。产生优质输出的路由会增强其信息素。主要贡献包括：

- **可解释的路由证据**。信息素强度是一种人类可读的信号。
- **质量门控异步更新**。仅在通过质量检查后更新信息素，将推理与学习解耦。
- 在多智能体路由基准测试上实现 **4.7 倍加速**。

质量门控至关重要：如果没有它，速度快但结果错误的智能体会积累信息素，导致系统锁定在错误的路由上。

### 何时在 LLM 中使用 PSO / ACO

**使用 PSO 的场景：**
- 搜索空间是连续的，或可映射到连续参数（提示词嵌入、LoRA 权重、数值生成参数）。
- 适应度计算成本低且自动化。
- 种群规模可以较小（10-30）。

**使用 ACO 的场景：**
- 存在路由或路径选择问题。
- 决策会随时间累积强化（相同类型的任务会反复出现）。
- 需要为路由决策提供可解释的证据。

**避免使用的场景：**
- 适应度评估需要人工审核（单次迭代成本过高）。
- 搜索空间是离散的，且以 PSO 无法覆盖的组合方式存在（应改用遗传算法）。
- 实时决策对延迟有严格要求（相对于单遍启发式算法，PSO/ACO 收敛较慢）。

### 为什么生物启发式算法依然占优

基于梯度的方法需要可微信号。LLM 输出和路由决策并非轻易可微。伪梯度方法（强化学习路由、DPO 风格的提示词微调器）有效，但需要昂贵的训练成本。

PSO 和 ACO 只需要一个*评估器*函数。如果你能对候选输出或路由决策进行打分，就可以在该空间上进行优化。这使得其适用门槛大大降低。

### 实际限制

- **种群预算**。N 个粒子 × T 次迭代 × 单次评估成本。对于 LLM 评估（约 $0.02/次调用），运行 50 次迭代的 20 粒子 PSO 成本约为 $20。请据此规划。
- **探索与利用的权衡**。信息素衰减速率与 PSO 惯性之间存在权衡；衰减过快会导致遗忘已有解；过慢则容易陷入早期的局部最优。
- **灾难性漂移**。如果适应度景观发生变化（如新的数据分布），两种算法都可能先收敛然后发散。需监控最佳适应度的稳定性。

## 构建实现

`code/main.py` 实现了：

- `LMPSO` —— 针对数值型提示词参数（temperature、top_k 权重）的 PSO。每个粒子的“LLM 生成”过程被模拟为脚本化的适应度函数。运行算法 30 次迭代并展示 g_best 的收敛情况。
- `AMRO_S` —— ACO 风格的路由。包含 3 个智能体、4 种任务类型、信息素矩阵和 100 次路由任务。按时间打印（task_type → agent choices）分布以展示轨迹形成过程。
- 对比实验：在同一任务流上对比随机路由与 ACO 路由。测量质量与延迟指标。

运行：

```
python3 code/main.py
```

预期输出：
- LMPSO：g_best 适应度在 30 次迭代内从随机水平提升至接近最优。
- AMRO-S：信息素表针对每种任务类型稳定在正确的智能体上；ACO 路由在质量上比随机路由高出约 30-40%，同时也降低了延迟（重试次数减少）。

`outputs/skill-swarm-optimizer.md` 帮助你在 LLM/智能体优化问题中，在 PSO、ACO、遗传算法和基于梯度的优化器之间做出选择。

## 交付建议

- **从小处着手**。使用 10-20 个粒子，运行 20-50 次迭代。仅在收敛曲线显示明确收益时才扩大规模。
- **记录每次迭代的信息素或 g_best**。没有轨迹日志的情况下调试群体优化器会非常痛苦。
- **实施质量门控更新**。特别是对于 ACO 路由：速度快但结果错误的智能体绝不能积累信息素。
- **分布偏移时重置衰减**。当评估分布发生变化时，陈旧的信息素已失效；此时应重置信息素或临时加倍衰减速率。
- **控制单次迭代成本**。输出单次迭代成本指标。单次迭代花费 $500 却仅提升 0.5% 的 PSO 不具备交付价值。

## 练习

1. 运行 `code/main.py`。观察 LMPSO 的收敛情况。将种群大小分别设置为 5、10、20、50。收敛所需时间在多大规模时趋于饱和？
2. 实现一个“灾难性漂移”实验：在第 30 次迭代后更改适应度函数。PSO 适应变化的速度有多快？重置 `p_best` 是否有帮助？
3. 为 AMRO-S 添加质量门控：仅在评估分数 > 0.7 的运行中沉积信息素。这与未加门控的版本相比，收敛情况有何变化？
4. 阅读 LMPSO (arXiv:2504.09247)。将论文中的“速度即提示词”映射回你的数值型速度。模拟过程中丢失了什么，又保留了什么？
5. 阅读 AMRO-S (arXiv:2603.12933)。实现带有异步信息素更新的解耦“推理快速通道”。这在持续负载下如何改变系统延迟？

## 核心术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| PSO | “粒子群优化” | Kennedy-Eberhart 1995。基于种群的无梯度优化器。 |
| ACO | “蚁群优化” | Dorigo 1992。通过信息素轨迹进行路径/路由优化。 |
| LMPSO | “结合 LLM 生成的 PSO” | arXiv:2504.09247。速度作为提示词；LLM 生成候选解。 |
| Model Swarms | “在专家权重上运行 PSO” | arXiv:2410.11163。在模型参数子空间上进行无梯度更新。 |
| AMRO-S | “用于智能体路由的 ACO” | arXiv:2603.12933。基于任务类型 × 智能体的信息素矩阵。 |
| p_best / g_best | “个人最优 / 全局最优” | 单个粒子及整个种群迄今为止找到的最佳解。 |
| Pheromone | “路由记忆” | 边上的强度值；随时间衰减；按质量沉积。 |
| Quality-gated update | “仅从优质运行中学习” | 信息素沉积以通过质量检查为前提条件。 |
| Catastrophic drift | “分布偏移” | 适应度景观发生变化；旧的 p_best 和信息素失效。 |
