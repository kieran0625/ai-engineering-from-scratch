# 投票、自洽性与辩论拓扑结构

> 最经济的聚合方式：采样 N 个独立智能体，进行多数投票。Wang 等人 2022 年的“自洽性（Self-Consistency）”研究通过让单个模型采样 N 次实现了这一点。多智能体方案通过引入**异构（heterogeneous）**智能体来打破同质化——使用不同的模型、提示词、温度参数和上下文。除了多数投票，辩论的拓扑结构至关重要：MultiAgentBench（arXiv:2503.01935，ACL 2025）评估了星型/链式/树型/图型协作，发现**图型拓扑最适合研究类任务**，且在约 4 个智能体以上时会出现“协调成本”。AgentVerse（ICLR 2024）记录了两种涌现模式——志愿者行为与从众行为，而从众既是特性（达成共识）也是风险（群体思维，见第 24 课）。本课将绘制拓扑结构图谱，构建每种变体，并测量协调成本。

**类型：** 学习 + 构建
**语言：** Python (stdlib)
**前置知识：** 第 16 阶段 · 07（心智社会与辩论），第 16 阶段 · 14（共识与 BFT）
**预计时间：** ~75 分钟

## 问题

辩论可以提高准确性（Du 等人，arXiv:2305.14325）。它也可能降低准确性。辩论是否有效取决于四个结构性选择：

1. 谁与谁交流（拓扑结构）。
2. 多少轮对话（Du 2023：轮数和智能体数量均独立影响结果）。
3. 智能体是否异构（不同的基础模型可打破同质化）。
4. 是否存在对抗性声音（最强论证与稻草人谬误的对比）。

许多团队只是简单地将“运行 5 个智能体并投票”硬套到任务上，结果往往比单个智能体表现更差。这些失败并非随机发生，而是与拓扑结构和异构程度密切相关。本课即为拓扑结构指南。

## 概念

### 自洽性，单模型基线

Wang 等人 2022 年（《自洽性提升思维链推理》）在温度参数 > 0 的情况下对同一模型采样 N 次，并对推理路径的答案进行多数投票。GSM8K 数据集上的结果显示：与单次贪婪解码相比，N=40 次采样带来了显著的性能提升。自洽性是面向多智能体投票的单智能体前身。

局限性：自洽性仅使用一个基础模型。错误在构造上具有相关性。如果模型存在系统性偏差，所有 N 次采样都会共享该偏差。

### 多智能体投票，异构扩展

用 N 个*不同*的智能体替换 N 次采样。使用不同的基础模型（Claude、GPT、Llama）、不同的提示词、不同的工具访问权限。优势在于错误不相关。代价是：不同智能体的调用成本各异；协调它们会增加额外开销。

异构辩论在 2026 年的标准名称为 **A-HMAD** —— 对抗性异构多智能体辩论（Adversarial Heterogeneous Multi-Agent Debate）。虽未成为绝对通用术语，但论文中常用此指代“不同模型进行辩论，从而减少因同质化崩溃导致的关联错误”。

### 四种拓扑结构

```
star                chain               tree                graph

    ┌─A─┐           A─B─C─D         ┌──A──┐              A───B
    │   │                           │     │              │ × │
    B   C                           B     C              D───C
    │   │                          / \   / \
    D   E                         D   E F   G           (fully connected)
```

星型（Star）：一个中心节点，其他节点仅与中心节点通信。等同于无反向通道的监督者-工作者架构。
链型（Chain）：线性结构，每个智能体只能看到前一个智能体的输出。类似流水线。
树型（Tree）：层级结构，常用于分层智能体系统（见第 06 课）。
图型（Graph）：任意节点间互通。包括全连接图和任意有向无环图（DAG）。

### 协调成本（MultiAgentBench）

MultiAgentBench（MARBLE，ACL 2025，arXiv:2503.01935）基准测试了在包含研究、编码和规划的任务套件上，星型、链型、树型和图型拓扑的表现。关键测量结果如下：

- **图型（Graph）** 拓扑在研究类任务中胜出。信息任意流动；智能体可以相互批判。
- **星型（Star）** 在快速回答事实类任务中胜出。中心节点负责过滤和整合。
- **链型（Chain）** 在逐步流水线任务（分阶段优化）中胜出。
- **协调成本（Coordination tax）** 在图型拓扑中超过约 4 个智能体后显现。实际耗时与 Token 成本的增长速度快于质量提升。

4 个智能体的瓶颈是经验性的，而非根本性的。它反映了 2026 年 LLM 的上下文容量限制：每个智能体的上下文会被同伴的输出填满，一旦所有人互相可见，增加第 N+1 个智能体的边际价值就会下降。

### 多智能体辩论策略（“我们是否应该走向 MAD？”）

arXiv:2311.17371 是 2023 年关于 MAD 策略的综述。其他研究复现的关键发现是：当预算相同时，那些在*结构上*与自洽性相似（独立采样 + 聚合）的 MAD 变体，往往表现不如自洽性。MAD 在智能体真正异构且辩论具有对抗性结构（即有一个智能体专门反驳）时效果最佳。

### AgentVerse 涌现模式

AgentVerse（ICLR 2024，https://proceedings.iclr.cc/paper_files/paper/2024/file/578e65cdee35d00c708d4c64bce32971-Paper-Conference.pdf）记录了即使在无显式设计的情况下，多智能体辩论中也会自然涌现的两种行为：

- **志愿者行为（Volunteer）**：智能体主动提供帮助（“我可以执行下一步”）。其作用在于将子任务分配给最擅长的智能体。
- **从众行为（Conformity）**：智能体会调整立场以迎合批评者，即使批评者是错的。这是辩论场景下的阿谀奉承（sycophancy）等价物（见第 14 课）。

从众行为解释了为何“辩论至达成一致”的策略会奖励强势方。通过限制最大轮数并引入独立的裁判/验证器可以缓解此问题。

### 异构性：真正影响准确性的关键变量

2024-2026 年实践文献中的一个普遍规律：将 N 个智能体中的一个替换为不同的基础模型，带来的准确率提升幅度大于单纯将 N 增加 1。直觉在于打破同质化——每一个新的独立误差源都比一个相关的重复采样更有价值。

在极限情况下，异构性优于数量。在大多数拥有清晰标准答案的任务中，三个不同的模型胜过五个相同模型的副本。

### 陪审团方法（Jury methods）

Sibyl 框架（引用自 Minsky-LLM 文献）形式化了“陪审团”机制——一组小型的专业化智能体，通过在每一阶段投票来优化答案。与简单的多数投票不同，陪审团具有明确的角色分工：一个智能体负责交叉质询，一个提供上下文，一个评估合理性。陪审团方法是介于简单投票（成本低、易陷入同质化）与完整 MAD（成本高、易产生从众）之间的中间路线。

### 何时辩论投票占优

- 问题存在标准答案（事实、数学、代码行为）。投票收敛具有意义。
- 智能体能够访问不同的数据源或工具（具备异构条件）。
- 轮数受限（通常为 2-3 轮）且设有独立的裁判或验证器。
- 预算允许调用 3-5 个智能体。在图型拓扑中超过 5-7 个智能体时，协调成本将占据主导。

### 何时辩论投票有害

- 问题是观点导向型的。智能体会收敛于看起来最自信的答案，而非最正确的答案。
- 所有智能体共享同一个基础模型。同质化会使共识失去意义。
- 轮数无限制。从众行为将始终获胜。
- 任务过于简单。使用自洽性（N=5）的单个智能体成本更低且准确率相当。

## 动手实现

`code/main.py` 实现了以下功能：

- `run_star(agents, hub, question)` —— 中心节点轮询各工作节点，并进行聚合。
- `run_chain(agents, question)` —— 顺序优化。
- `run_tree(root, children, question)` —— 带有深度-2 聚合的层级结构。
- `run_graph(agents, question, rounds)` —— 全互联辩论，限制轮数。
- 一个脚本化的异构调节旋钮：每个智能体拥有一个 `error_bias` 指示其系统性错误倾向。
- 一个测量框架，在 N=3、5、7 下运行每种拓扑结构，并报告（准确率、总 Token 数、模拟实际耗时）。

运行：

```
python3 code/main.py
```

预期输出：一张展示拓扑结构 × N →（准确率、Token 数、延迟）的表格。在研究类任务中，N=3-5 时图型拓扑胜出；在快速事实类任务中，星型拓扑胜出；N=7 时的图型拓扑会显示协调成本（延迟膨胀速度快于准确率提升）。

## 应用场景

`outputs/skill-topology-picker.md` 是一个技能模块，用于读取任务描述并推荐拓扑结构（星型/链型/树型/图型）、N（智能体数量）、异构配置（使用的 base models）以及轮数上限。

## 部署建议

对于任何集成方案：

- 首先使用一个强大的基础模型进行 **N=5 的自洽性采样**。这是低成本基线。
- 如果准确率至关重要，升级为 **N=3 的异构投票**。测量性能差异。
- 仅当任务具有结构化特征（如研究、多步骤）且可实现有限轮数时，才升级为 **辩论拓扑结构**。
- 始终记录少数派集群。当少数派持续正确时，你便获得了多样性信号。
- 将实际耗时与 Token 消耗与准确率一同记录。“以 10 倍成本换取更好准确率”是一个商业决策。

## 练习

1. 运行 `code/main.py`。绘制图型拓扑的协调成本曲线：准确率 vs N，Token 数 vs N。曲线在哪个 N 值处出现拐点？
2. 实现 A-HMAD：三个具有故意不同偏差的智能体。在第 14 课的“同质化攻击”测试中，全同偏差基线与 A-HMAD 的表现如何对比？
3. 为图型拓扑添加一个“裁判”角色，该角色不参与投票，仅对最终共识进行评分。这会改变涌现的从众行为吗？
4. 阅读 AgentVerse 论文（ICLR 2024）。识别你的实现中最强烈地表现出哪种涌现行为。能否通过修改提示词激发相反的行为？
5. 阅读 MultiAgentBench（arXiv:2503.01935）第 4 节（拓扑实验）。使用你的测量框架复现论文中某个任务的“图型在研究中胜出”的结果。

## 核心术语

| 术语 | 常见说法 | 实际含义 |
|------|----------------|------------------------|
| Self-consistency（自洽性） | “采样 N 次并投票” | Wang 2022。单模型，N 次温度>0 采样，对推理路径进行多数投票。 |
| Heterogeneity（异构性） | “不同模型” | 不同基础模型或提示词家族的集成。打破同质化。 |
| MAD | “多智能体辩论” | 泛指智能体在多轮中交换批评的通用术语。参见 Du 2023。 |
| A-HMAD | “对抗性异构 MAD” | 强调不同模型 + 对抗结构的 MAD 变体。 |
| Topology（拓扑结构） | “谁与谁交流” | 星型、链型、树型、图型。决定信息流向。 |
| Coordination tax（协调成本） | “收益递减” | 图型拓扑中超过约 4 个智能体后，成本增长快于质量提升。 |
| Volunteer behavior（志愿者行为） | “主动提供帮助” | AgentVerse 涌现模式：智能体主动提出执行某一步骤。 |
| Conformity behavior（从众行为） | “压力下的妥协” | AgentVerse 涌现模式：智能体迎合批评者的立场。 |
| Jury（陪审团） | “小型专业小组” | 类似 Sibyl 的带角色分工的集成方案（审查员、上下文提供者、评分员）。 |
